# SQL & Databases — Verbal Questions

All questions in this section are verbal-only. The Piston code runner executes code in a sandbox and cannot run SQL against a live database, so candidates are not asked to write and execute queries here.

Instead, the database track tests explanation and schema reasoning: normalization, index internals, transaction semantics, JOIN behavior, and scaling strategies are evaluated by how clearly a candidate explains the concepts and tradeoffs.

Answers are scored against the `idealAnswer` and `keyPoints` fields, with `minWords` enforcing a minimum response length.
